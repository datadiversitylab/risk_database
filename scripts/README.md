# IUCNN risk database

Predicted extinction risk for species that are undescribed, unassessed, or listed as
Data Deficient by the IUCN. 

## Groups

    01-amphibians
    02-reptiles
    03-chondrichthyans
    04-freshwater
    05-orchids
    06-birds
    07-mammals

## Structure

    <group>/code/            R and Python for that group
    <group>/data/raw/        Downloads as they arrived, not tracked
    <group>/data/processed/  Feature tables and versioned predictions
